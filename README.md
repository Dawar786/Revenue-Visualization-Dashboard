# 📊 Revenue Visualization Dashboard

An interactive dashboard built with **Chart.js** to visualize key financial metrics such as **Revenue, Profit, and Expenses** across months.  
This project demonstrates how data can be transformed into clear, insightful visualizations using modern web technologies.

visit the webpage here : https://revenuedashboardchart.netlify.app/

---

## 🔍 Features
- **Line Chart**: Displays **Revenue, Expenses, and Profit** trends across months for comparative analysis.
- **Bar Chart**: Focuses solely on **Revenue by month**, making it easy to spot growth patterns.
- **Pie Chart**: Breaks down **Reinvestment, Miscellaneous, and Salaries**, showing the composition of expense categories.

---

## 🛠️ Tech Stack
- **Chart.js** → For creating responsive and interactive charts
- **HTML5 & CSS3** → Structure and styling
- **JavaScript** → Data handling and chart configuration

---

## 📂 Dataset
The dataset includes:
- **Revenue** (monthly)
- **Profit** (monthly)
- **Expenses** (monthly)
- **Expense Categories**: Reinvestment, Miscellaneous, Salaries
